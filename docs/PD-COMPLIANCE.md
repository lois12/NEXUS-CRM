# Персональные данные — чек-лист (публичные формы)

*Техническая памятка. Юр. формулировки и уведомление в РКН — с юристом / оператором.*

Область: **только публичные формы** (`/opros/*`, `/reg/*`).  
Сотрудники внутри CRM — отдельный кадровый контур (не по этому чек-листу).

---

## 1. Уведомление в Роскомнадзор (РКН)

- [ ] Юр. лицо / ИП — оператор ПД (то, кто владеет сайтом / мероприятием)
- [ ] Подать уведомление: [zkn.rkn.gov.ru](https://zkn.rkn.gov.ru) (форма оператора)
- [ ] Указать: цели (мероприятия / опросы / информирование), категории ПД (ФИО, телефон, email, ответы), субъекты (участники / респонденты), правовое основание (согласие), хранение в РФ
- [ ] Назначить ответственного за организацию обработки ПД (можно в приказе)
- [ ] Сохранить копию уведомления / регистрационный номер

## 2. Политика (уже на сайте)

- [x] `/privacy-policy.html` — оператор, цели, состав ПД, срок **3 года**, права (§9), уничтожение (§8)

## 3. Согласие на формах (код)

- [x] Чекбокс + ссылка на политику (опросы, регистрации)

- [x] Без согласия submit публичного опроса отклоняется

## 4. Права субъекта

- [x] Страница `/pd-request` — отзыв / удаление / выгрузка / исправление
- [x] Футер публичных форм: «Политика ПД» + «Отзыв согласия / Мои данные»
- [ ] Регламент обработки запросов — см. §5 ниже

## 5. Регламент «30 рабочих дней» (внутри команды)

1. Запрос приходит в **Админка → Обратная связь** (фильтр `[ПД:...]`)
2. Ответственный (назначить приказом) принимает заявку **в день поступления**
3. Идентификация: совпадение email/телефона с заявкой в опросе/регистрации
4. Срок ответа: **до 30 рабочих дней** (можно быстрее)
5. Действия:
   - **отзыв / удаление** — удалить или обезличить запись (`survey_responses` / `registration_submissions`), при необходимости файлы
   - **выгрузка** — CSV/PDF по ответам субъекта
   - **исправление** — правка полей
6. Ответ отправить тем же контактом, сохранить переписку 3 года
7. Отказ — только по основаниям закона, с обоснованием
