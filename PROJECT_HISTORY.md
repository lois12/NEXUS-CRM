# PROJECT_HISTORY — история работы над NEXUS CRM

## 2026-10-04 — Большая сессия: аудит, конвертеры, коллаж, чат, безопасность

### Глубокий анализ проекта (3 параллельных аудита)
- **Безопасность**: 7 находок (1 critical, 2 high, 4 medium)
- **Архитектура**: 1 critical, 4 high, 5 medium
- **UI/UX + производительность**: 3 P0 мобильных бага, регрессия дизайн-системы

### Критические фиксы безопасности (задеплоены, `2a9012d`)
- **C1**: `protectPdf` при ошибке удалял всю папку `uploads/` (127 файлов). Фикс: чистит только `jobDir`
- **C2**: JWT_SECRET на VPS проверен — 64-символьный случайный, не дефолтный ✅
- **H1**: Stored XSS через uploads — расширения файлов теперь по серверному allowlist + `nosniff`/`CSP sandbox` на `/uploads`
- **H2**: Файлы конвертера удалялись после 1-го скачивания — теперь живут до TTL 1 часа
- **H4**: Подпись/замазка не работали на телефоне — `onPointer*` события
- **H5–H7**: Чат — badge непрочитанных без скрытых, липкость скрытия, возврат в группу
- **M1–M12**: IDOR скачивания, пароль PDF в логах, mute UI, мультисheet CSV, ZIP для split, /tmp 0700, история-журнал, категории хаба

### Конвертер документов (`/doc-converter`) — 20+ инструментов
- **v1** (`aa22120`): Office→PDF (LibreOffice), PDF→Word/Excel, merge/split/watermark, JPG→PDF, CSV↔XLSX
- **v2** (`c9b7836`): поворот, организовать страницы (drag-and-drop миниатюры), номера, обрезка, сжатие, ZIP
- **v3** (`9e4f398`): подпись мышью, замазка с превью, защита паролем (qpdf), PDF→PPTX, история конвертаций
- **LibreOffice 26.2.5.2 + qpdf 12.3.2** установлены на VPS (apt, БД не тронута)
- Фикс EXDEV: `rename` между `uploads/` и `/tmp` заменён на `copy+unlink`

### Коллаж из фото (`/photo-collage`) — редактор зон
- **v1** (`ff483ea`): сетки 2×2/3×3/1+2, gap, фон
- **v2** (`98fa68b`): живое превью с drag-and-drop смены фото
- **Зоны** (`98fa68b`+): rect/circle/ellipse/diamond + произвольный полигон (рисование точками)
- **v3** (`4521a66`): fullscreen, скругление картинок (imgRadius), текст с 20 шрифтами на кириллице (Google Fonts), z-индекс (↑↓→|слой N|)
- **v4** (`b6b9f44`): undo/redo стрелками, зум/сдвиг фото в зоне, направляющие (снап к центру/краям), рамка по контуру фигуры, обводка текста + наклон ±45°, 4 угла по отдельности, меню фигур иконками (+треугольник, звезда, сердце, шестиугольник, арка)
- Фикс качества экспорта (`38189b0`): пошаговый даунскейл (mip-mapping), `imageSmoothingQuality: 'high'`, экспорт 1x/2x
- Фикс полигонов (`1e16803`): точки нормализуются к bbox зоны (превью=экспорт)
- Фикс drop фото на зону (`2f441c4`): `onDragOver`/`onDrop` на зонах + ресайз-хэндл вне overflow

### Сокращатель ссылок (`/short-links`)
- Любая ссылка → `nexus-liberty.online/s/{code}` (7 символов, crypto.randomBytes)
- Публичный 302-редирект, свои ссылки (список/копировать/удалить), идемпотентность по URL+юзеру
- Миграция `017 short_links` (аддитивная)

### Чат — удаление и 2 аудита
- Удаление чатов: ПКМ-меню (pin/mute/delete), Telegram-style подтверждение, реальное удаление групп, выход из группы
- Миграция `016 chat_hidden` — per-user скрытие
- Аудит-фикс (`76117b1`): история общего чата (не грузилась — 404), пагинация (последние 50, не первые), `chat:join` для general, mute UI 🔇
- Аудит-фикс (`015f691`): 7 багов (socket-слушатели, isMuted, липкость hide, и т.д.)

### Контент-план и аналитика
- Убраны согласования — пишут super_admin + smm, все смотрят (`4dd24be`)
- Аналитика: «????» в статусах (мусорный статус в БД), последние действия только контент-план
- CONTACT-модалка в Базе регистраций: копирование + Telegram/WhatsApp/VK/МАКС
- МАКС: на телефоне — Web Share API с выбором приложения, на десктопе — web.max.ru + копирование

### CONTROL (F6)
- Пароль для `/control`: bcrypt в `app_settings`, JWT `scope: 'control'`, гейт на публичных эндпоинтах
- Миграция `015 app_settings`

### Архитектура
- Типизированный DB-слой (`query<T>`/`get<T>`), `buildUpdate`, `transaction()`, `errorHandler` + `asyncHandler`
- `server/types/index.ts` — row-типы (пока не используется повсеместно)
- `update.sh` фикс: `git pull` больше не может молча провалиться (lock-файлы npm install)

### VPS — установлено
- LibreOffice 26.2.5.2 (`/usr/bin/soffice`)
- qpdf 12.3.2
- БД на VPS **не тронута** ни разу за всю сессию (только read-only SELECT проверки)
