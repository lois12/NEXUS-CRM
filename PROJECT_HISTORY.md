## Правила дизайна

### Плейсхолдеры
Все плейсхолдеры должны быть в стиле киберпанк:
- Начинаются с `//` (имитация кода)
- Caps Lock (верхний регистр)
- Технический/хакерский слог
- Моноширинный шрифт (JetBrains Mono)
- Полупрозрачный цвет (30% от основного)

Примеры:
- `// ИДЕНТИФИКАТОР ОПЕРАТОРА`
- `// ПОИСК В БАЗЕ ДАННЫХ...`
- `// ВВЕДИТЕ ПРОМПТ ДЛЯ НЕЙРОСЕТИ...`
- `// СКАНИРОВАНИЕ ХРАНИЛИЩА...`

### Темы
- Все цвета задаются через CSS переменные (`--color-primary`, `--color-glow` и т.д.)
- При добавлении новых элементов использовать переменные, а не хардкод цветов
- Анимация при смене тем обязательна

### Типографика
- Заголовки: моноширинный шрифт, неоновое свечение
- Основной текст: Inter
- Технические элементы: JetBrains Mono

### Иконки
- **ЗАПРЕЩЕНО** использовать эмодзи в интерфейсе
- Все иконки — Lucide React или кастомные SVG
- Иконки должны быть в цвете темы (`var(--color-primary)`)
- Размеры: 16px (маленькие), 20px (средние), 24px (большие)
- Стиль: outline, с тонкими линиями, минималистичные
- Соцсети: кастомные SVG-иконки (Telegram, VK) в цвете площадки
